# Разграничение контекста

*Обновлено: 16 октября 2026*

## Раздел 1: Как добавить контекст

**Что такое контекст?**

Контекст — информация, которую ИИ использует при подготовке ответов: текст, таблицы Excel, PDF-файлы и другое. Источники: история текущего чата, прикреплённые файлы, базы знаний, специализированные ассистенты. Точность выбора контекста напрямую улучшает качество ответов.

### Метод 1: Прикрепить файл к чату

Используйте для работы с одним или несколькими документами в рамках одного диалога.

*Когда использовать:* анализ отдельных документов, подготовка отчётов, поиск информации в конкретных файлах, сравнение нескольких файлов.

*Как использовать:* создайте новый чат → нажмите кнопку прикрепления файла → выберите документ → дождитесь загрузки → задайте вопрос о содержимом документа.

### Метод 2: Использовать базу знаний (Knowledge)

База знаний — набор документов по определённым темам.

*Когда использовать:* большое количество документов, корпоративные инструкции, регламенты, справочная информация отдела.

*Как использовать:* создайте новый чат → нажмите «Прикрепить базу знаний» → выберите базу знаний → задайте вопрос.

### Метод 3: Использовать специализированного ассистента/модель

Некоторые модели настроены для конкретных задач с предустановленными параметрами (промпты, настройки модели, инструменты) и знаниями. Примеры: деловая переписка, инструкции по безопасности, поиск подрядчиков, геологический анализ.

*Когда использовать:* когда вопросы относятся к конкретным областям знаний.

## Раздел 2: Open Terminal

Стандартный Open WebUI обращается к файлам в Open Terminal через код и скрипты, включая «Инструменты». Спросив «Покажи файлы в рабочем каталоге», модель выберет наиболее подходящий инструмент. Запросите доступные инструменты: «Какие инструменты доступны?»

**Важно:** наличие файла в Open Terminal не гарантирует автоматического использования его содержимого в каждом запросе. Рекомендуемый подход — создавать «Инструменты», читающие конкретные файлы из Open Terminal через функции Python.

Для создания «Инструментов» обратитесь к alsu.yarulina@areal.ru.

## Раздел 3: Как очистить контекст

Когда ответы включают старую информацию или обращаются к предыдущим задачам, рекомендуется очистить контекст.

### Метод 1: Создать новый чат

Простой и рекомендуемый способ. Новые чаты начинаются без истории предыдущего диалога.

*Когда использовать:* переход к новым задачам, смена проектов, работа на разные темы.

### Метод 2: Удалить прикреплённые файлы

Найдите список вложений → удалите ненужные файлы → повторите запрос.

*Когда использовать:* когда ответы должны опираться только на новые документы.

### Метод 3: Отключить базу знаний

Откройте список подключённых баз знаний → удалите или отключите текущую базу → подключите альтернативную при необходимости.

*Когда использовать:* переход между рабочими областями (HR, юридические вопросы, инженерная документация, аналитика).

### Метод 4: Переключить специализированного ассистента

Разные ассистенты используют разные инструкции и базы знаний. Создайте новый чат и выберите другую модель.
