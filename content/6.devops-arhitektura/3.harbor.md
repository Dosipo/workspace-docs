Harbor хранит образы контейнеров. Он работает в namespace `harbor` внутри [Kubernetes](/devops-arhitektura/kubernetes).

## Что видно на схеме

- В namespace `harbor` показан один компонент: Harbor API.
- Снаружи к нему идёт соединение по **TCP/8443**.
- Со схемы Harbor API связан стрелкой с Gitlab shell из namespace `gitlab`.

## Уточнить

::caution
Схема не описывает следующее.
::

- адрес и доменное имя Harbor;
- смысл связи с GitLab (например, push образов из CI) — на схеме только стрелка;
- где Harbor хранит данные, в том числе [SeaweedFS](/devops-arhitektura/seaweedfs) или [PostgreSQL](/devops-arhitektura/postgresql) — не подтверждено.
