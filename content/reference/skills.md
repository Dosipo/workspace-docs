**Скилл** — это специализированная инструкция, которую агент Multica загружает перед выполнением задачи. Скилл добавляет экспертизу: знание библиотеки, стандарт оформления, набор критериев проверки.

Скиллы устанавливаются на уровне воркспейса и доступны всем агентам. Агент сам выбирает, какой скилл использовать, исходя из задачи.

## Текущие скиллы

::card-group

::card{title="create-docs" icon="heroicons:document-plus"}
Создаёт полноценные сайты документации для проектов. Используется, когда нужно сгенерировать docs-сайт, инициализировать Docus, написать документацию «с нуля».
::

::card{title="review-docs" icon="heroicons:magnifying-glass"}
Аудирует существующую документацию: ясность, структура, корректность MDC-синтаксиса, техническая точность. Не проверяет SEO-аспекты.
::

::card{title="okf-convert" icon="heroicons:arrow-path-rounded-square"}
Конвертирует произвольные файлы (markdown, txt, csv, json, yaml, html, sql) в бандл Open Knowledge Format (OKF) v0.1. Используется при создании каталогов знаний или приведении документов к OKF-стандарту.
::

::card{title="nuxt-ui" icon="heroicons:squares-plus"}
Экспертиза по @nuxt/ui v4 — 125+ компонентов с Tailwind CSS-темизацией. Используется при создании интерфейсов, кастомизации тем, построении форм и лейаутов (дашборды, docs-сайты, чат-интерфейсы).
::

::card{title="frontend-design" icon="heroicons:paint-brush"}
Направляет дизайн-решения при построении нового UI или переработке существующего: типографика, визуальный язык, выбор паттернов оформления. Помогает не скатиться в «шаблонный» вид.
::

::card{title="Shadcn UI" icon="heroicons:cube-transparent"}
Создание доступных и кастомизируемых интерфейсов с shadcn/ui, Radix UI и Tailwind CSS. Настройка shadcn, установка компонентов, формы с React Hook Form + Zod, кастомизация тем.
::

::card{title="web-design-guidelines" icon="heroicons:check-badge"}
Проверяет UI-код на соответствие Web Interface Guidelines: доступность, UX, паттерны взаимодействия. Используется при аудите дизайна или UI-ревью.
::

::

## Когда агенты используют скиллы

Агент сам решает, когда загружать скилл, на основе описания задачи. Чтобы скилл точно был применён, опишите задачу конкретно:

::note
Вместо «сделай красиво» → «создай UI-компонент карточки на Nuxt UI, соответствующий нашим гайдлайнам»
::

## Добавление новых скиллов

Новые скиллы устанавливает администратор воркспейса через настройки Multica. Если нужного скилла не хватает — поставьте задачу Mika.
