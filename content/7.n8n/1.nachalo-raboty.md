# Начало работы с n8n

*Обновлено: 7 октября 2026*

Корпоративный n8n: **https://n8n.geotech.user.events/**

Доступ через SSO или пароль с доменной авторизацией.

## 1. Создание workflow вручную

Workflows собираются из готовых блоков — нод.

### Пример: чат с моделью Gemini 3.7 Flash

**Три ноды workflow:**
- Chat with User (Chat Trigger) — открывает интерфейс чата, получает сообщения пользователя
- Ask Model (OpenAI → Message a model) — отправляет вопрос модели, получает ответ
- Response to Chat (Respond to Chat) — возвращает ответ модели в окно чата

### Шаг 1: Создайте workflow

Нажмите «Create workflow» и назовите его.

### Шаг 2: Добавьте Chat Trigger

- Нажмите `+` на рабочем пространстве
- Найдите «Chat Trigger», выберите «On new chat event»
- Настройте:
  - **Make Chat Publicly Available:** включите для доступа по ссылке из браузера
  - **Mode:** Hosted Chat
  - **Authentication:** None
  - **Initial Message(s):** приветственный текст
  - **Options → Response Mode:** Using Response Nodes
- Переименуйте ноду в «Chat with User»

### Шаг 3: Добавьте ноду OpenAI

- Нажмите `+` справа от ноды чата
- Найдите «OpenAI», выберите «Message a model»
- Настройте:
  - **Credential:** OpenAi account 2
  - **Resource:** Text
  - **Operation:** Message a Model
  - **Model:** geotech/gemini/gemini-3.7-flash
  - **Messages → Prompt:** `Отвечай кратко и по делу на русском. Вопрос: {{ $json.chatInput }}`

> Выражение `{{ $json.chatInput }}` должно быть в режиме Expression.

- Переименуйте в «Ask Model»

### Шаг 4: Добавьте ноду ответа

- Нажмите `+` справа от ноды модели
- Найдите «Edit Fields»
- Настройте Mode: Manual Mapping
- Добавьте поле:
  - **Name:** output
  - **Type:** String
  - **Value:** `{{ $json.output[0].content[0].text }}`
- Переименуйте в «Response to Chat»

### Шаг 5: Сохраните и протестируйте

- Сохраните: Ctrl+S
- Нажмите «Open chat»
- Отправьте тестовый вопрос
- Успешный ответ — ноды подсвечиваются зелёным

### Шаг 6: Поделитесь ссылкой

- Откройте ноду Chat Trigger
- Скопируйте Chat URL
- Активируйте workflow (кнопка Publish)
- Поделитесь ссылкой с коллегами

## Что можно менять

- **Инструкция модели:** измените текст промпта (сохраняйте `{{ $json.chatInput }}`)
- **Выбор модели:** любая LLM из [списка доступных моделей](/modeli)
- **Приветственное сообщение:** поле Initial Message(s)

> Для моделей с рассуждениями (o3, gpt-5.4) ответ может быть в `output[1]`, а не в `output[0]`.

## Ошибки в workflow

n8n подсвечивает проблемные ноды красным. Для отладки:
- Откройте выполнение workflow
- Нажмите на красную ноду
- Проверьте поля Error message, Error details, Stack trace

**Распространённые причины:** неверные пути к файлам, отсутствующие credentials, нет доступа к Nextcloud, недоступные модели, неверный endpoint, пустые или некорректно отформатированные входные файлы.

## 2. Создание workflow через JSON-импорт

Workflows хранятся как `.json` файлы и могут быть импортированы в n8n.

**Процесс импорта:**
1. Скачайте JSON-файл workflow
2. Откройте n8n, нажмите «Create workflow»
3. В меню `...` (правый верхний угол) выберите «Import from File»
4. Выберите скачанный файл
5. Проверьте поле «Credential to connect with» — должен быть выбран `OpenAi account 2`

Запускайте workflow через кнопку «Open chat», а не через «Execute».

## 3. Экспорт workflow в JSON

**Когда нужно:**
- Поделиться workflow с другими пользователями
- Создать резервную копию перед изменениями
- Использовать как основу для других проектов

Credentials экспортируются только как ссылки и требуют повторного выбора после импорта.
