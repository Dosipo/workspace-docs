# Список доступных нод n8n

*Обновлено: 22 октября 2026*

Краткое описание каждой ноды из списка разрешённых: назначение и типичные сценарии. Ноды, не перечисленные здесь, недоступны в корпоративном n8n.

## Триггеры (запуск workflow)

| Нода | Назначение |
|------|-----------|
| Manual Trigger | Запуск вручную кнопкой — для тестирования и разовых задач |
| Schedule Trigger | Запуск по расписанию (cron, интервалы). Периодические задачи: отчёты, синхронизации, мониторинг |
| Webhook | Приём HTTP-запросов извне. Входная точка для интеграций, ботов, форм |
| Chat Trigger | Запуск диалога чата (n8n UI или встроенный виджет) для ИИ-ассистентов |
| GitLab Trigger | События GitLab: push, merge request, issue — для CI/CD-автоматизации |
| Microsoft Outlook Trigger | События почты/календаря Outlook: новое письмо, встреча |
| Telegram Trigger | Входящие сообщения и команды Telegram-бота |
| Execute Workflow Trigger | Точка входа подпроцесса — вызывается через Execute Workflow из другого workflow |

## AI / LangChain

| Нода | Назначение |
|------|-----------|
| AI Agent | Автономный агент: инструменты (tools), память, LLM; сам решает порядок действий |
| Chat OpenAI | Чат-модель OpenAI (GPT) как LLM-провайдер для агента/цепочек |
| OpenAI | Прямые операции OpenAI: генерация текста, транскрипция, изображения |
| Embeddings OpenAI | Векторные эмбеддинги текста через OpenAI. Загрузка и поиск в векторной базе |
| Vector Store PGVector | Векторное хранилище PGVector (PostgreSQL): сохранение, поиск, удаление эмбеддингов |
| Default Data Loader | Загрузка документов (текст, PDF, CSV) для индексации в векторное хранилище |
| Character Text Splitter | Разбивка текста на чанки фиксированного размера по числу символов |
| Recursive Character Text Splitter | Иерархическая разбивка текста (по абзацам, предложениям) с сохранением связности |
| Memory Manager | Управление историей чата: чтение, обновление, очистка памяти агента |
| Postgres Chat Memory | Хранение истории диалога в PostgreSQL. Персистентная память чат-агента |
| Mistral AI | Модели Mistral: генерация текста, чат |

## Базы данных

| Нода | Назначение |
|------|-----------|
| Postgres | CRUD и SQL-запросы к PostgreSQL |
| Postgres Tool | PostgreSQL как инструмент ИИ-агента для автономного написания и выполнения запросов |
| MySQL | Запросы к MySQL/MariaDB |
| Microsoft SQL | Запросы к MS SQL Server |
| NocoDB | Таблицы NocoDB: чтение/запись строк |

## Файлы и хранилища

| Нода | Назначение |
|------|-----------|
| S3 | Работа с S3-совместимым объектным хранилищем (AWS S3, MinIO и др.) |
| Nextcloud | Файлы Nextcloud: загрузка, скачивание, управление |
| Convert to File | Данные в файл (JSON, CSV, XLSX, PDF и др.) |
| Extract from File | Извлечение данных из файла (парсинг CSV, Excel, XML, PDF) |

## Связь и интеграции

| Нода | Назначение |
|------|-----------|
| HTTP Request | Произвольные HTTP-запросы к любому API. Универсальный интегратор |
| Respond to Webhook | Ответ на входящий Webhook-запрос (контроль статуса и тела ответа) |
| Execute Workflow | Запуск другого workflow как подпрограммы с передачей данных |
| Email Send | Отправка писем через SMTP |
| Microsoft Outlook | Операции Outlook: письма, календарь, контакты |
| Telegram | Отправка сообщений, файлов, кнопок в Telegram |
| Mattermost | Сообщения и операции в Mattermost |
| GitLab | Операции GitLab API: репозитории, MR, issues, файлы |
| Firecrawl | Веб-скрапинг/краулинг сайтов через Firecrawl: страницы в чистый markdown |

## Обработка данных

| Нода | Назначение |
|------|-----------|
| Code | Произвольный JavaScript/Python код для трансформации данных |
| Set | Присваивание и переименование полей (настройка значений) |
| IF | Условное ветвление |
| Switch | Множественное ветвление по правилам |
| Merge | Слияние потоков данных из нескольких веток |
| Split In Batches | Пакетная обработка: разбивка на батчи (циклы с ограничением размера) |
| Split Out | Разбивка одного элемента с массивами на отдельные элементы |
| Aggregate | Сборка элементов в один: массивы, сводки |
| Remove Duplicates | Удаление дубликатов по ключу |
| Limit | Ограничение количества элементов |
| Sticky Note | Заметки на канвасе (документация workflow, не влияет на данные) |

## Кастомные ноды (CUSTOM)

| Нода | Назначение |
|------|-----------|
| litellmOcr | OCR через LiteLLM: распознавание текста из изображений/сканов |
| perplexitySearch | Веб-поиск через Perplexity: ответы со ссылками на источники |
| browserUse | Управление браузером: навигация, скрапинг, действия на страницах |
| pptxMaker | Генерация PowerPoint-презентаций из данных |
