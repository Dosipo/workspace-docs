# Демо: загрузка данных из Data table

*Обновлено: 22 октября 2026*

## Что делает workflow

Workflow демонстрирует работу с таблицами данных прямо в n8n (раздел **Data tables**). Читает строки со статусом `active` из таблицы, затем добавляет новую строку «Тестовый рудник».

Data tables подходят для небольших справочников, списков, логов и промежуточных результатов.

## Как загрузить

**Файлы:**
- `Демо. data_table_gold_mining.json`
- `test_table.csv` (тестовые данные: 10 операций золотодобычи)

**Шаги:**
1. Создайте таблицу в разделе Data tables и загрузите данные из `test_table.csv`
2. Скачайте `Демо. data_table_gold_mining.json`
3. Откройте n8n, нажмите «Create workflow»
4. В меню `...` выберите «Import from File» и укажите скачанный файл
5. В нодах «Get active mines» и «Insert new mine» укажите ID вашей таблицы
6. Сохраните workflow и нажмите «Execute workflow»

## Где находятся Data tables

Data tables — раздел n8n для хранения таблиц данных. Доступен на главной странице (Overview) и странице проекта на вкладке **Data tables** (рядом с вкладками Workflows, Credentials, Executions).

**Создание таблицы:**
1. Откройте вкладку **Data tables**
2. Нажмите «Create data table»
3. Назовите, например `gold_mines`
4. Выберите способ создания:
   - **Import CSV** — загрузите готовый файл
   - **From scratch** — создайте пустую таблицу с нужными столбцами
5. Проверьте типы столбцов: числа должны быть Number, даты — Date, остальные — String

> **Важно:** таблица принадлежит проекту, в котором создана. Таблица в Personal проекте видна только вам. Для доступа коллег создавайте в общем проекте.

## Как найти ID таблицы

Откройте таблицу в Data tables. ID — последняя часть адреса браузера после `/datatables/`:

```
https://n8n.geotech.user.events/projects/<project id>/datatables/0ojSnbXrxYcO0sRb
```

Здесь ID таблицы: `0ojSnbXrxYcO0sRb`. Укажите ID в нодах «Get active mines» и «Insert new mine».

## Из чего состоит workflow

| Нода | Тип ноды | Что делает |
|------|----------|-----------|
| When clicking 'Execute workflow' | Manual Trigger | Запуск вручную |
| Get active mines | Data table → Get row(s) | Получает строки со статусом `active` |
| Insert new mine | Data table → Insert row | Добавляет строку «Тестовый рудник» |

## Особенности

- **Фильтрация строк:** нода «Get active mines» использует условие `status` = `active`. Включён **Return All** — возвращает все совпадающие строки
- **Значения новой строки задаются в ноде:** в «Insert new mine» значения столбцов введены вручную. `report_date` задаётся выражением: `{{ $now.toFormat('yyyy-MM-dd') }}`
- **Нода добавляет строку столько раз, сколько элементов вернула предыдущая нода.** Для добавления одной строки: в «Insert new mine» → вкладка **Settings** → включите **Execute Once**
- **Data tables не заменяют базы данных** — они подходят для небольших объёмов. Для больших таблиц и сложных запросов используйте [PostgreSQL](/n8n/postgresql)

## Credentials

Credentials не нужны: Data tables хранятся внутри n8n, нода Data table обращается к ним без отдельного доступа.
