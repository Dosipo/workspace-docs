# Демо: OCR файлов в папке Nextcloud

*Обновлено: 7 октября 2026*

## Что делает workflow

Workflow распознаёт текст в PDF и изображениях (OCR) из папки Nextcloud и сохраняет результат рядом в виде Markdown-файлов. Подходит для сканов документов, фотографий страниц и PDF без текстового слоя.

## Как загрузить

1. Скачайте файл **Демо. OCR файлов в папке Nextcloud.json** (прикреплён к инструкции)
2. Откройте n8n и нажмите «Create workflow»
3. В меню `...` выберите «Import from File» и укажите скачанный файл
4. Проверьте credentials в нодах Nextcloud и в ноде «Распознать текст»
5. Сохраните workflow

## Как пользоваться

1. Положите файлы в папку Nextcloud `n8n/OCR/input`: https://cloud.ide-spb.com/apps/files/files/108020739?dir=/n8n
2. В n8n нажмите «Execute workflow»
3. Дождитесь, пока все ноды подсветятся зелёным
4. Заберите результаты из папки `n8n/OCR/output`

## Из чего состоит workflow

| Нода | Тип ноды | Что делает |
|------|----------|-----------|
| When clicking 'Execute workflow' | Manual Trigger | Запуск вручную |
| Список файлов во входной папке | Nextcloud → List a Folder | Получает список файлов в `n8n/OCR/input` |
| Выбрать файлы для OCR | Code | Оставляет поддерживаемые форматы и готовит пути для результатов |
| Скачать файл из Nextcloud | Nextcloud → Download a File | Скачивает каждый файл |
| Распознать текст | LiteLLM OCR | Распознаёт текст |
| Подготовить результат | Code | Превращает ответ OCR в `.md` файл или файл с ошибкой |
| Сохранить результат в Nextcloud | Nextcloud → Upload a File | Сохраняет результат в `n8n/OCR/output` |

## Особенности

- **Поддерживаемые форматы:** `pdf`, `png`, `jpg`, `jpeg`, `webp`. Остальные файлы и папки пропускаются
- **Обрабатываются все файлы папки за один запуск.** Проверки «уже распознан» нет — при повторном запуске все файлы из `input` отправляются в OCR снова. Обработанные файлы лучше убирать из входной папки
- **Где искать результат.** Для каждого файла в `n8n/OCR/output` появляется:
  - `<имя файла>.md` — распознанный текст (если OCR прошёл успешно)
  - `<имя файла>.error.txt` — описание ошибки (если OCR не справился)
- **Ошибка на одном файле не останавливает обработку остальных**
- **OCR-модель:** `mistral-ocr-latest` — специализированная OCR-модель, возвращающая текст с разметкой Markdown

## Credentials

| Нода | Credential |
|------|-----------|
| Список файлов, Скачать файл, Сохранить результат | NextCloud account |
| Распознать текст | LiteLLM OCR New |

Оба credential общие, находятся во вкладке «Shared with you». Если после импорта поле credential пустое или выделено красным — выберите нужный credential вручную.

## Что можно поменять

- **Входная папка** — поле Folder Path в ноде «Список файлов» и переменная `inputDir` в коде ноды «Выбрать файлы для OCR» (менять в обоих местах)
- **Выходная папка** — переменная `outputDir` в коде ноды «Выбрать файлы для OCR» (папка должна существовать в Nextcloud)
- **Список форматов** — переменная `allowed` в коде ноды «Выбрать файлы для OCR»
- **OCR-модель** — поле Model в ноде «Распознать текст»
