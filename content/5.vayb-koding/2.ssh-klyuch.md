# Как создать и добавить SSH-ключ для Git

*Обновлено: 6 июля 2026*

SSH-ключ нужен, чтобы подключаться к GitHub или GitLab без ввода логина и пароля при каждом обращении к репозиторию.

## Что потребуется

- Установленный Git
- Доступ к Git Bash или терминалу
- Аккаунт GitHub или GitLab
- Email, используемый в аккаунте GitHub или GitLab

> **Предупреждение:** Никому не отправляйте приватный ключ. Приватный ключ обычно лежит в файле без расширения, например `id_ed25519`. В GitHub или GitLab добавляют только **публичный** ключ — файл с расширением `.pub`, например `id_ed25519.pub`.

## Что такое SSH-ключ

SSH-ключ состоит из двух частей:
- **Приватный ключ** — остаётся только на вашем компьютере
- **Публичный ключ** — добавляется в GitHub или GitLab

При подключении к репозиторию по SSH сервис проверяет, что публичный ключ в учётной записи соответствует приватному ключу на вашем компьютере.

## Как создать SSH-ключ

1. Откройте Git Bash или любой другой терминал

2. Выполните команду:

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

Замените `your_email@example.com` на email из вашего GitHub или GitLab.

3. Нажмите Enter, подтверждая предложенное имя файла и папку

4. При запросе passphrase нажмите Enter снова, если парольная фраза не нужна

**Ожидаемый результат:** в папке `.ssh` появятся два файла ключа — обычно `id_ed25519` и `id_ed25519.pub`.

## Проверка ключей в терминале

```bash
cd ~/.ssh
ls
```

## Как найти публичный ключ

Публичный ключ находится в файле с расширением `.pub`. Обычно путь: `~/.ssh/id_ed25519.pub`

**Как открыть файл вручную:**
1. Перейдите в папку `.ssh`
2. Найдите файл `id_ed25519.pub` или другой файл с расширением `.pub`
3. Нажмите правой кнопкой мыши на файл
4. Выберите «Открыть с помощью» → текстовый редактор
5. Скопируйте всё содержимое файла

Ключ должен начинаться с `ssh-ed25519` или `ssh-rsa`.

**Скопировать через терминал (Windows):**

```bash
cat ~/.ssh/id_ed25519.pub | clip
```

## Как добавить SSH-ключ в GitHub

1. Войдите в GitHub
2. В правом верхнем углу выберите аватар → Settings
3. В левом меню выберите **SSH and GPG keys**
4. В поле key вставьте содержимое публичного ключа
5. Убедитесь, что ключ скопирован полностью (начинается с `ssh-ed25519` или `ssh-rsa`)
6. В поле title введите название (например: `key_name`)
7. Нажмите **Add key**

**Ожидаемый результат:** SSH-ключ появился в списке ключей GitHub.

## Частые проблемы

| Что случилось | Возможная причина | Что делать |
|---|---|---|
| Команда `ssh-keygen` не найдена | Git не установлен или терминал не видит Git | Установите Git и откройте Git Bash |
| Нет файла `id_ed25519.pub` в `.ssh` | Ключ сохранён под другим именем | Найдите файл с расширением `.pub` |
| Сервис не принимает ключ | Скопирована не вся строка ключа | Откройте `.pub` снова и скопируйте ключ полностью |
| Git запрашивает пароль при работе с репозиторием | Репозиторий подключён через HTTPS, а не SSH | Проверьте remote-адрес и используйте SSH-адрес репозитория |
