# Как добавить Rules и Skills в IDE

*Обновлено: 1 июля 2026*

Rules и Skills помогают ИИ-агенту работать с 1С-кодом по нужным правилам: соблюдать стиль, учитывать особенности языка и структуру файлов, выбирать правильный способ решения задачи.

## Что потребуется

- IDE (Visual Studio Code + Kilo Code или Cursor)
- Rules: https://github.com/comol/ai_rules_1c
- Skills: https://github.com/Nikolay-Shirokov/cc-1c-skills и/или https://github.com/Nikolay-Shirokov/cc-1c-skills/tree/port-kilo

## Что такое Rules?

Rules — текстовые инструкции для агента. Они описывают, как писать код, какие стандарты соблюдать, что нельзя менять и как проверять результат. Rules обычно хорошо переносятся между инструментами. Совместимость между Cursor и VS Code + Kilo Code: 95–100%.

## Что такое Skills?

Skills — более специализированные инструкции и файлы для конкретных задач. Примеры: внешние обработки, управляемые формы, роли, конструктор запросов, метаданные, XML-файлы, веб-тестирование. Совместимость между инструментами: 85–95%.

## Добавление Rules в VSCode + Kilo Code

**Метод 1:**

1. Откройте проект в Visual Studio Code
2. Откройте Kilo Code в боковой панели
3. Отправьте запрос:

```
Установи правила для 1С из https://github.com/comol/ai_rules_1c по AGENT-INSTALL.md.
Устанавливай для Kilo Code. Перед заменой существующих файлов покажи, что изменится.
```

4. Дождитесь подготовки изменений агентом
5. Просмотрите список изменённых файлов
6. Подтвердите установку, если изменения касаются правил проекта

**Ожидаемый результат:** В проекте появятся или обновятся файлы правил для Kilo Code и общие файлы инструкций агента.

## Добавление Rules в Cursor

1. Откройте проект в Cursor
2. Откройте чат или Agent
3. Отправьте запрос:

```
Установи правила для 1С из https://github.com/comol/ai_rules_1c по AGENT-INSTALL.md.
Устанавливай для Cursor. Перед заменой существующих файлов покажи, что изменится.
```

4. Дождитесь подготовки изменений
5. Просмотрите список
6. Подтвердите установку

## Добавление Skills в VSCode + Kilo Code

1. Откройте репозиторий Skills: https://github.com/Nikolay-Shirokov/cc-1c-skills
2. Найдите версию для Kilo Code: ветка `port-kilo`
3. Скачайте архив через Code → Download ZIP
4. Распакуйте архив
5. Скопируйте папку skills в проект, создав директорию `.kilocode/skills/`
6. Перезапустите Visual Studio Code или обновите окно IDE

**Ожидаемый результат:** Kilo Code может использовать 1С-навыки из папки `.kilocode/skills/`.

## Добавление Skills в Cursor

1. Откройте репозиторий Skills: https://github.com/Nikolay-Shirokov/cc-1c-skills
2. Найдите версию для Cursor: ветка `port-cursor`
3. Скачайте архив через Code → Download ZIP
4. Распакуйте архив
5. Скопируйте папку skills в проект, создав директорию `.cursor/skills/`
6. Перезапустите Cursor или обновите окно IDE

## Проверка подключения Rules и Skills

1. Откройте чат агента в Cursor или Kilo Code
2. Отправьте запрос:

```
Проверь, какие правила и навыки для 1С доступны в этом проекте.
Файлы не изменяй.
```

3. Убедитесь, что агент упоминает правила или навыки 1С
4. Для дополнительной проверки:

```
Открой один .bsl-файл и скажи, какие правила 1С ты будешь учитывать при ревью.
Файлы не изменяй.
```

Если агент отвечает общими словами и не ссылается на файлы правил — убедитесь, что в корне открытого проекта существуют папки `.cursor/`, `.kilo/` или `.kilocode/`.
