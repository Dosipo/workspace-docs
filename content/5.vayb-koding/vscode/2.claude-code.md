# Claude Code для VSCode

*Обновлено: 7 сентября 2026*

Эта инструкция поможет подготовить рабочее пространство для написания кода с помощью ИИ, используя расширение Claude Code for VS Code с личным API-ключом.

## Раздел 0: Определения

- **Visual Studio Code** — редактор кода
- **Claude Code** — расширение Anthropic, добавляющее в VS Code ИИ-ассистента для написания кода, управления файлами и агентных задач
- **Провайдер/Прокси** — адрес, куда расширение отправляет запросы к модели: `https://litellm.geotech.user.events`
- **Глобальный файл настроек** — `settings.json` в папке `.claude` домашнего каталога пользователя

## Раздел 1: Установите Visual Studio Code

См. [инструкцию по установке VSCode](/vayb-koding/vscode/ustanovka).

## Раздел 2: Установите расширение Claude Code

1. Откройте Extensions в VS Code (`Ctrl+Shift+X` на Windows/Linux; `Cmd+Shift+X` на macOS)
2. Найдите «Claude Code»
3. Выберите **Claude Code for VS Code** от **Anthropic** (идентификатор: `anthropic.claude-code`)
4. Нажмите Install
5. Дождитесь завершения; перезапустите, если иконка не появится
6. Откройте панель Claude Code один раз (это создаст папку `.claude`); закройте экран входа в аккаунт

## Раздел 3: Настройте глобальный файл настроек

**Пути к файлу по операционной системе:**
- Windows: `C:\Users\<Имя_пользователя>\.claude\settings.json`
- macOS: `/Users/<Имя_пользователя>/.claude/settings.json`
- Linux: `/home/<Имя_пользователя>/.claude/settings.json`

> **Критическое предупреждение:** Не путайте файлы. У VS Code есть собственный `settings.json` (открывается через Preferences: Open User Settings). Нужен файл в папке `.claude`, а не настройки VS Code.

**Шаг 1:** Откройте существующий файл через File → Open File (`Ctrl+O`), вставьте полный путь и нажмите Enter.

**Шаг 2:** Если файл не найден — создайте новый (`Ctrl+N`), сохраните как (`Ctrl+Shift+S`), введите полный путь включая `.claude\settings.json`.

**Шаг 3:** Вставьте конфигурацию, заменив `ваш-API-ключ` на ваш реальный ключ:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://litellm.geotech.user.events",
    "ANTHROPIC_AUTH_TOKEN": "ваш-API-ключ"
  },
  "model": "geotech/gemini/gemini-3.7-flash",
  "modelPicker": {
    "options": [
      {
        "model": "geotech/gemini/gemini-3.7-flash",
        "label": "Gemini 3.7 Flash"
      },
      {
        "model": "geotech/zai/glm-5.3-flash",
        "label": "GLM-5.3 Flash"
      },
      {
        "model": "geotech/openai/gpt-5.6-luna",
        "label": "GPT Luna"
      },
      {
        "model": "geotech/gemini/gemini-3.5-flash",
        "label": "Gemini 3.5 Flash"
      },
      {
        "model": "gti-local/Qwen3.8",
        "label": "Qwen3.8 (Local)"
      }
    ]
  },
  "availableModels": [
    "geotech/gemini/gemini-3.7-flash",
    "geotech/zai/glm-5.3-flash",
    "geotech/openai/gpt-5.6-luna",
    "geotech/gemini/gemini-3.5-flash",
    "gti-local/Qwen3.8"
  ],
  "permissions": {
    "allow": [],
    "ask": [],
    "deny": []
  }
}
```

**Требования к формату файла:**
- Строгий JSON: без комментариев (`//`) и без лишних запятых
- API-ключ — полностью, без лишних пробелов
- Сохраните файл (`Ctrl+S`) и перезапустите VS Code

## Раздел 4: Откройте Claude Code и выберите модель

1. Нажмите иконку Claude Code в боковой панели VS Code
2. Нажмите на название модели внизу поля ввода для выбора модели из `availableModels`
3. Выбор модели:
   - **Sonnet** — основная модель для большинства задач
   - **Opus** — сложные задачи, требующие высокой точности
   - **Haiku** — самая быстрая и дешёвая, для простых правок

## Раздел 5: Проверка

1. Откройте панель Claude Code
2. Введите простой запрос (например: «Напиши сортировку пузырьком на 1С»)
3. Если Claude Code ответил — настройка завершена

## Раздел 6: Диагностика

Проверьте:
- VS Code версии 1.94.0 или новее
- Расширение Claude Code от Anthropic установлено
- `settings.json` находится в папке `.claude` домашнего каталога, а не в настройках VS Code
- JSON корректен: без комментариев, без лишних запятых, все скобки закрыты
- Плейсхолдер заменён реальным API-ключом
- `ANTHROPIC_BASE_URL` указан без суффикса `/v1`
- Файл сохранён и VS Code перезапущен

При сохраняющихся проблемах: alsu.yarulina@geotech.in

## Безопасность API-ключа

> API-ключ действует на сотрудника, которому он был выдан. Не передавайте ключ никому и не публикуйте его в чатах, документах или скриншотах. Файл `settings.json` с ключом остаётся только локально — не коммитьте его в репозитории.
