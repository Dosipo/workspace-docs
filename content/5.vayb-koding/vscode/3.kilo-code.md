# Kilo Code для VSCode

*Обновлено: 14 августа 2026*

Kilo Code — расширение для Visual Studio Code, которое позволяет подключить LLM-модель и использовать агентный подход для работы с кодом. ИИ-помощник может помогать писать код, объяснять файлы, предлагать исправления и выполнять часть действий по задаче.

## Раздел 0: Определения

- **Visual Studio Code** — редактор кода
- **Kilo Code** — расширение для VS Code с LLM-интеграцией через API-ключ
- **Провайдер** — подключение к модели, через которое Kilo Code отправляет запросы

## Раздел 1: Установите Visual Studio Code

См. [инструкцию по установке VSCode](/vayb-koding/vscode/ustanovka).

## Раздел 2: Установите расширение Kilo Code

1. В Visual Studio Code откройте раздел Extensions
2. Найдите «Kilo Code»
3. Выберите расширение Kilo Code
4. Нажмите Install
5. После установки откройте Kilo Code в боковой панели

## Раздел 3: Добавьте провайдера в настройки Kilo Code

Провайдер — это подключение к модели, через которое Kilo Code отправляет запросы.

1. Откройте настройки Kilo Code
2. Перейдите в раздел Providers
3. Нажмите кнопку «+ Connect» рядом с «Custom provider»
4. Заполните поля:
   - Provider ID, Display name — любые значения
   - Provider API — **OpenAI Responses** или **OpenAI Compatible**
   - Base URL — `https://litellm.geotech.user.events/v1`
5. Вставьте личный API-ключ в поле API key

   Если у вас нет API-ключа, запросите его у alsu.yarulina@geotech.in

6. Добавьте нужные модели

   ID модели есть в [списке доступных моделей](/modeli). Название модели — любое.

7. Сохраните настройки, нажав «Submit»

## Раздел 4: Проверьте работу

1. Откройте Kilo Code в Visual Studio Code
2. Выберите нужную модель
3. Напишите простой запрос: «Напиши код пузырьковой сортировки на 1С»
4. Отправьте запрос
5. Если Kilo Code ответил — настройка завершена

## Раздел 5: Если возникла ошибка

Проверьте:
- Visual Studio Code (с синей иконкой) установлен
- Расширение Kilo Code установлено
- Выбран правильный раздел Providers
- Все поля заполнены как описано
- API-ключ вставлен полностью, без лишних пробелов
- Интернет-соединение доступно

При сохраняющейся ошибке — напишите alsu.yarulina@geotech.in.

## Безопасность API-ключа

> API-ключ действует на сотрудника, которому он был выдан. Не передавайте ключ никому и не публикуйте его в чатах, документах или скриншотах.
