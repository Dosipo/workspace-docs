# Работа с ИИ в IDE

*Обновлено: 1 июля 2026*

## Что потребуется

- Установленная IDE: Visual Studio Code, Cursor или другая
- Экспортированный 1С-проект в виде файлов
- Доступ к ИИ-инструменту: подписка Cursor или API-ключ для подключения к модели

> **Предупреждение:** Не открывайте в ИИ конфиденциальные данные, персональные данные, пароли, токены, строки подключения и реальные клиентские базы.

## Что такое IDE?

IDE — рабочее пространство разработчика для кода. Вы можете открыть папку проекта, просматривать файлы, искать по проекту, редактировать код, запускать команды и добавлять расширения.

ИИ может объяснять код, находить ошибки, предлагать изменения и готовить исправления, но окончательную проверку выполняет разработчик.

## Различие VSCode и Cursor

**Visual Studio Code** — универсальный редактор кода. Хорошо подходит как основа для управляемой корпоративной настройки, где компании могут отдельно выбирать расширения, ИИ-ассистентов, модели, правила доступа и ограничения.

**Cursor** — IDE на базе Visual Studio Code, но со встроенными инструментами ИИ. Включает редактор, чат по проекту, агентные процессы, автодополнение и функции контекста кодовой базы.

## Компоненты ИИ + IDE

| Компонент | Аналогия |
|-----------|----------|
| Cursor или VS Code | Офис, где открыт проект и доступны рабочие инструменты |
| LLM | Мозг, который умеет читать текст, рассуждать и писать код |
| Агент | Сотрудник, получающий задачи, планирующий шаги и выполняющий действия |
| Rules | Корпоративные инструкции: стиль кода, запреты, стандарты проекта |
| Skills | Накопленная экспертиза по конкретным задачам: ревью, тесты, миграции, 1С |
| Инструменты | Конкретные инструменты: IDE, Git, терминал, поиск, линтер, браузер |
| MCP | Доступ к внешним системам: GitHub, Jira, Confluence, базам данных, файловым хранилищам |

**Ключевой принцип:** Агент работает лучше, когда видит нужные файлы, получает чёткую задачу и ограничен правилами проекта.

## Как создать рабочую папку проекта

1. Создайте отдельную папку в Проводнике (например, `crm_config_review`)
2. Выгрузите в неё конфигурацию, расширение, внешнюю обработку или отчёт
3. Убедитесь, что файлы и подпапки видны внутри
4. Не смешивайте несколько несвязанных конфигураций в одной папке

## Как открыть проект в IDE

1. Откройте Visual Studio Code или Cursor
2. Нажмите File → Open Folder
3. Выберите папку с 1С-проектом
4. Если IDE спрашивает, доверяете ли вы папке, подтверждайте только для проектов из надёжных источников
5. Откройте панель Explorer слева
6. Убедитесь, что видите дерево файлов проекта

## Как ограничить контекст ИИ

ИИ тратит время и токены на чтение файлов. Больше ненужных открытых папок — больше риск, что агент будет искать не там или изменит не тот файл.

Перед задачей:
1. Откройте только нужную папку проекта
2. Закройте несвязанные проекты и большие архивы
3. Укажите агенту конкретные файлы или папки
4. Уточните, какие файлы нельзя менять
5. Попросите показать план сначала, если задача затрагивает несколько модулей

**Пример запроса:**
```
Анализируй только папку CommonModules/ОбменДанными.
Найди, где формируется пакет обмена.
Пока ничего не меняй, сначала покажи план исправлений.
```

## Расширения для 1С

Расширение — это дополнение к IDE. Оно может добавлять подсветку синтаксиса, поиск метаданных, форматирование, интеграцию с Git.

**Полезные расширения для 1С:**
- **Language 1C** — подсветка синтаксиса `.bsl` файлов
- **1C Metadata Viewer** — просмотр дерева метаданных

**Как установить расширение в Visual Studio Code:**
1. Откройте VSCode
2. Нажмите иконку Extensions слева
3. Найдите «Language 1C» или название другого расширения
4. Откройте карточку расширения
5. Проверьте автора, описание и дату обновления
6. Нажмите Install
7. Откройте `.bsl` файл и убедитесь, что появилась подсветка синтаксиса
