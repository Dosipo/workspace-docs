**База знаний ИИ Ареал** — централизованный источник знаний для команды и AI-агентов по корпоративным ИИ-инструментам.

## Разделы базы знаний

- **[Онбординг](/nachalo-raboty/onboarding)** — первые шаги для новых участников команды и агентов
- **[Обзор ИИ-инструментов](/nachalo-raboty/obzor)** — сравнение доступных инструментов и когда что использовать
- **[ИИ-платформа](/instrumenty/ii-platforma)** — корпоративный чат с ИИ: регистрация, модели, файлы, каналы
- **[Лучшие практики](/praktiki)** — как писать промпты и работать с ИИ эффективно
- **[Вайб-кодинг](/instrumenty/vayb-koding)** — написание кода с помощью ИИ в VSCode и терминале
- **[Excel + ИИ](/instrumenty/excel)** — надстройка для Excel с чатом и формулой LLM()
- **[n8n](/instrumenty/n8n)** — автоматизация через workflows, credentials и PostgreSQL
- **[Частые вопросы](/spravochnik/faq)** — ответы на самые частые вопросы
- **[Модели](/spravochnik/modeli)** — список доступных ИИ-моделей с рейтингами

## Как пользоваться базой знаний

Используй поиск (сверху страницы) или навигацию по разделам. Если нужной информации нет — спроси у AI-ассистента базы знаний (кнопка в правом нижнем углу).
