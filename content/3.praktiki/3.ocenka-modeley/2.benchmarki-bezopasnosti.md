Используйте эти бенчмарки, чтобы сравнивать модели и защиты по устойчивости к вредным запросам и атакам. Смотрите на две стороны сразу: отказы на опасное и ложные отказы на безобидное.

::warning
Модель, которая отказывает всем, получит отличную «безопасность» и провалит XSTest. Всегда добавляйте метрику ложных отказов.
::

## Бенчмарки

| Бенчмарк | Что меряет | Как применять |
|---|---|---|
| [HarmBench](https://arxiv.org/abs/2402.04249) | Стандартизированная оценка автоматического red teaming: 18 методов атаки на 33 модели и защиты | ASR (доля успешных атак) для сравнения моделей и защит |
| [AgentHarm](https://arxiv.org/abs/2410.09024) | Вредные агентные задачи в 11 категориях; 110 задач, 440 с аугментациями; проверяет отказ и сохранность способностей | Оценка агентов с инструментами; авторы отмечают, что модели «удивительно послушны» даже без джейлбрейка |
| [JailbreakBench](https://arxiv.org/abs/2404.01318) | 100 поведений, репозиторий jailbreak-артефактов, единая методика и лидерборд | Сопоставимое сравнение атак и защит |
| [StrongREJECT](https://arxiv.org/abs/2402.10260) | Запретные запросы и автооценщик, измеряющий, насколько ответ реально помогает вреду | Вместо бинарного «отказал или нет»; прежние оценщики завышали успех джейлбрейков |
| [XSTest](https://arxiv.org/abs/2308.01263) | Ложные отказы: 250 безопасных промптов 10 типов и 200 небезопасных для контраста | Противовес «безопасности» |
| [TruthfulQA](https://arxiv.org/abs/2109.07958) | Склонность повторять заблуждения; 817 вопросов, 38 категорий | Историческая база, для новых моделей почти насыщен; для RAG лучше свои проверки фактов |
| [BBQ](https://arxiv.org/abs/2110.08193) | Предвзятость в QA по 9 социальным осям | Ограничение: США и английский язык |
| [WMDP](https://arxiv.org/abs/2403.03218) | 3 668 вопросов по био-, кибер- и химбезопасности как прокси опасных знаний | Для frontier-рисков; для наших сценариев малоприменим |
| [CyberSecEval](https://arxiv.org/abs/2404.13161) | Риски в кибербезопасности, включая prompt injection, и ложные отказы; у всех оценённых моделей 26–41% успешных инъекций | Единственный в списке с тестами на инъекции вместе с ложными отказами |
| [AgentDojo](https://arxiv.org/abs/2406.13352) | Окружение для агентов: 97 задач и 629 тестов безопасности, расширяемое | Основной инструмент для непрямых инъекций у агентов |
| [InjecAgent](https://arxiv.org/abs/2403.02691) | 1 054 тест-кейса на непрямые инъекции через вывод инструментов | Оценка агентов с инструментами |
| [MLCommons AILuminate](https://arxiv.org/abs/2503.05731) | 12 категорий вреда, пятиуровневая оценка от Poor до Excellent; только одноходовые диалоги | Сопоставимая оценка рисков общего назначения |

::note
Размеры наборов HarmBench, StrongREJECT, BBQ и AILuminate при подготовке страницы по аннотациям не подтверждены, поэтому не указаны. Список категорий AILuminate сверяйте с официальным.
::

## Как применять

1. Определите риски вашего сценария. Для чат-ассистента нужны отказы и ложные отказы, для агента — AgentHarm и AgentDojo.
2. Прогоняйте безопасность и ложные отказы вместе, одной таблицей.
3. Не полагайтесь на публичные наборы как на единственный тест: они попадают в обучающие данные. Добавьте свои случаи в [голденсет](/praktiki/ocenka-modeley/goldensety).
4. Для сценариев с внешними данными переходите к [проверке на промпт-инъекции](/praktiki/ocenka-modeley/prompt-inyekcii).

Публичные цифры безопасности Claude смотрите в анонсах вендора; сводка бенчмарков качества — на странице [Бенчмарки Claude](/instrumenty/claude/benchmarki).
