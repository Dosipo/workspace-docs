# Как добавить ИИ в Excel через собственную надстройку

*Обновлено: 23 сентября 2026*

Надстройка позволяет работать с ИИ прямо в Excel через окно чата, формулу LLM() и пакетную обработку ячеек. Работает как альтернатива, когда Claude for Excel недоступен из-за корпоративных ограничений.

> **Только Windows.** На macOS и в браузерном Excel этот метод не работает: отсутствует компонент MSXML для отправки запросов.

## Ключевые компоненты надстройки

| Компонент | Описание |
|-----------|----------|
| **Окно чата** (Ctrl+Shift+K) | Вопросы о выделенных ячейках, листах или всей книге; запросы на изменение таблиц и написание формул |
| **Функция LLM()** | Стандартная формула таблицы, возвращающая ответ модели в ячейку |
| **Пакетная обработка** (Ctrl+Shift+J) | Запросы для каждой выделенной ячейки, результаты в соседний столбец |
| **Отмена ИИ-правок** | Отмена последних изменений ИИ (до 20 шагов) |

## Фаза 1: Сборка надстройки

1. Создайте новую пустую книгу Excel
2. Откройте редактор VBA (Alt+F11)
3. Импортируйте модуль `ai_excel_addins.bas`
4. Создайте UserForm с именем `frmLLMChat`
5. Вставьте код интерфейса чата из `LLMChat_code.txt`
6. Добавьте привязки горячих клавиш в ThisWorkbook
7. Скомпилируйте и сохраните как Excel Add-in (.xlam)

## Фаза 2: Подключение надстройки

1. Откройте File → Options → Add-ins
2. Выберите управление Excel Add-ins
3. Установите галочку `ai_excel_addins`
4. Перезапустите Excel

## Фаза 3: Настройка подключения

Настройки хранятся в реестре Windows (однократная настройка):
- **LiteLLM-адрес:** `https://litellm.geotech.user.events/v1/chat/completions`
- **API-ключ:** личный ключ доступа
- **Модель по умолчанию:** ID модели (например, `anthropic/claude-sonnet-5`)
- **Список моделей:** ID через запятую
- **Язык ответа:** Русский или Английский
- **Макс. токены чата:** по умолчанию 4000
- **Макс. токены LLM():** по умолчанию 1000

## Фаза 4: Проверка

- Выделите ячейки и нажмите «Объяснить выделение» в окне чата
- Введите формулу: `=LLM("Сгенерируй 3 названия отчёта")`
- Убедитесь, что ответы появляются в обоих местах

## Использование окна чата

**Варианты данных для контекста:**
- Выделенные ячейки: значения и формулы из выделенного диапазона
- Весь лист: все заполненные ячейки текущего листа
- Обзор книги: первые 15 заполненных строк каждого листа
- Без данных: только вопрос

**Доступные кнопки:**
- «Объяснить выделение» — анализ выделенных ячеек
- «Новый чат» — сброс памяти разговора
- «Формула в ячейку» — вставить формулу в активную ячейку
- «Ответ в ячейки» — распределить ответ по ячейкам
- «Отменить правки ИИ» — откат изменений (до 20 шагов)
- «Сохранить чат на лист» — экспорт разговора
- «Настройки» — изменить конфигурацию
- «Очистить кэш LLM()» — удалить кэшированные ответы

## Использование функции LLM()

Формула принимает: запрос (обязательно), диапазон данных (опционально), инструкции, модель, температуру, макс. токены.

Примеры:
```
=LLM("Переведи на английский"; A2)
=LLM("Найди аномалии продаж"; A1:D50)
=LLM("Сделай выводы"; A:F)
=LLM("Подведи итоги"; Sheet2!A:Z)
```

> В английской версии Excel используйте запятую вместо точки с запятой.

## Пакетная обработка ячеек

**Метод 1 — Протяжка формулы:**
Напишите формулу в ячейке и протяните вниз.

**Метод 2 — Макрос (предпочтительно для больших объёмов):**
1. Выделите диапазон одного столбца (например, A2:A201)
2. Нажмите Ctrl+Shift+J
3. Введите текст промпта
4. Ответы записываются как значения в соседний столбец B
5. Прогресс отображается в строке статуса

## Важные замечания

- «Ответы от =LLM() запоминаются до закрытия Excel. Если формула пересчитывается с идентичными входными данными — новый платный запрос не отправляется.»
- Для обновления: нажмите «Очистить кэш LLM()», затем Ctrl+Alt+F9
- Перед отправкой файлов другим: преобразуйте формулы в значения (Копировать → Специальная вставка → Значения)
- Горячие клавиши работают **только с английской раскладкой клавиатуры**

## Частые ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Compile error: Invalid outside procedure» | Посторонний текст вне процедур (слово «vba» из заголовка блока кода) | Удалите выделенную строку, повторите Debug → Compile VBAProject |
| «Ambiguous name detected» | Модуль импортирован дважды или подключены две версии надстройки | Оставьте один модуль `ai_excel_addins`, отключите старую версию |
| Ctrl+Shift+K не открывает чат | Активна русская раскладка | Переключитесь на английскую; при необходимости через Alt+F8 → `ai_excel_addins.xlam!LLM_Chat` → Выполнить |
| Ячейка показывает `#NAME?` | Надстройка не подключена | Повторите Фазу 2, убедитесь, что галочка установлена |

## Безопасность

> **Защита API-ключа:** Никогда не передавайте ключ и не публикуйте в чатах, документах, скриншотах. Не встраивайте в код модуля, ячейки или поле «Инструкции». Храните только в поле «API Key» настроек. На чужих/общих компьютерах: не вводите учётные данные (хранятся открытым текстом в реестре Windows).
>
> **Конфиденциальность данных:** Все данные из =LLM() и окна чата отправляются через прокси geotech. При выборе «Весь лист» или «Обзор книги» — весь лист/книга передаётся. Убедитесь в отсутствии чувствительной информации.
