После этих шагов вы получите работающего агента, который выполнил вашу первую задачу. Нужна облачная версия Multica; для самостоятельного развёртывания смотрите [Self-host quickstart](https://multica.ai/docs/self-host-quickstart).

::note
Компьютеру, на котором будут работать агенты, нужен хотя бы один поддерживаемый ИИ-инструмент (например, Claude Code, Codex или Cursor), установленный и авторизованный. Multica их не поставляет.
::

::steps
### Войдите

Откройте [multica.ai](https://multica.ai/) или приложение Multica Desktop. Подойдёт код подтверждения по почте или вход через Google.

### Подключите компьютер

В боковом меню откройте **AI Team → Runtimes**.

- В Desktop компьютер регистрируется сам и находит установленные инструменты. После установки нового нажмите **Refresh**.
- В веб-версии или для другого компьютера нажмите **Add** и выберите **Other machine or server**. Затем выполните в терминале целевой машины (macOS/Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/multica-ai/multica/main/scripts/install.sh | bash
multica setup
```

`multica setup` открывает браузер для входа и оставляет демон работать в фоне. Вариант для Windows есть в том же диалоге.

Проверка: онлайн-компьютер появился в списке runtimes.

### Создайте агента

Откройте **AI Team → Agents** и нажмите **New agent**. Выберите инструмент на подключённом компьютере, укажите имя и создайте агента кнопкой Create agent.

Кнопка **Let AI write it** поручает заполнение настроек Agent Builder; для неё runtime должен быть онлайн.

Проверка: агент в списке и помечен как онлайн.

### Дайте ему задачу

Нажмите **New Issue** (или клавишу `C`), в режиме агента выберите агента, коротко опишите задачу и отправьте. Агент назначается и сразу начинает работу.

### Проверьте результат

Откройте задачу: в ней видны журнал выполнения и ответы агента. **View transcript** показывает полную запись.

Проверка: статус запуска — Completed, в ленте есть ответ.
::

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Runtime не найден | Проверьте, что инструмент запускается в терминале; нажмите **Refresh** (Desktop) или повторите `multica setup` (CLI) |
| Runtime офлайн | Держите Desktop открытым или выполните `multica daemon status`, при необходимости `multica daemon start` |
| Задача остаётся в очереди | Убедитесь, что runtime онлайн; при достижении лимита параллельных запусков новые ждут |
