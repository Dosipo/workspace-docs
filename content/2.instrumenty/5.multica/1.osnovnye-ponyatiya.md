Страница объясняет, из каких объектов состоит Multica и как они связаны. После неё понятно, что происходит между назначением задачи и результатом.

## Словарь

| Понятие | Что это |
|---|---|
| Рабочее пространство (workspace) | Замкнутая область, где работает команда: в ней хранятся вся работа и настройки, участвуют люди и агенты |
| Задача (issue) | Единица работы: описание, обсуждение, статус и история. Исполнитель — участник, агент или squad |
| Проект | Объединяет связанные задачи вокруг одной цели; к нему можно привязать ресурсы, например репозитории |
| Агент | ИИ-участник, заданный как настраиваемая конфигурация: имя, инструкции, модель, навыки и runtime. Это не постоянный процесс: агент работает только после запуска |
| Навык (skill) | Переиспользуемый пакет знаний о том, как выполняется определённый тип работы. Один навык можно подключить многим агентам |
| Runtime | Место выполнения: компьютер, подключённый к Multica, и ИИ-инструменты на нём |
| Запуск (run) | Одна запись о выполнении работы агентом. Каждый триггер создаёт запуск; у задачи их может быть несколько |
| Squad | Группа агентов и участников с агентом-лидером; при назначении задачи на squad лидер координирует работу |
| Автопилот (autopilot) | Запускает агентов автоматически — по расписанию или по внешним событиям, а также вручную |
| Чат | Разговор с агентом вне задачи; каждое сообщение создаёт запуск |
| Входящие (inbox) | Центр уведомлений участника-человека: подписки, упоминания, назначения |

## Как это работает

Агент и среда выполнения разделены: агент — это личность и настройки, runtime — машина, которая работает.

1. Запуск начинается только по явному действию: назначение задачи, упоминание агента, сообщение в чате или автопилот.
2. Multica ставит запуск в очередь. Если ни один runtime не в сети, запуск ждёт.
3. Runtime на подключённом компьютере забирает запуск и стартует локальный ИИ-инструмент, выбранный для агента.
4. Инструмент работает в рабочей папке на вашем компьютере: читает файлы, выполняет команды, формирует результат.
5. Прогресс, комментарии и итог записываются в ленту задачи и журнал выполнения.

::note
Статус «Completed» у запуска означает только завершение этого запуска. Задача при этом может остаться открытой: в ней могут появиться новые требования или обсуждение.
::

## Что хранит сервер и что — ваш компьютер

- **Сервер Multica** хранит рабочие пространства, задачи, комментарии, статусы, настройки агентов, навыки и записи запусков.
- **Подключённый компьютер** исполняет: на нём установлены ИИ-инструменты с их учётными данными, код и локальные файлы, и именно там выполняются команды.

::warning
Значения из поля `custom_env` агента хранятся на сервере и передаются на runtime при запуске. Секреты, которые должны оставаться локальными, туда не кладите.
::
