OpenCode — опенсорс ИИ-ассистент в терминале; может писать код, управлять файлами, выполнять команды.

## Понятия

- **OpenCode** — опенсорс ИИ-ассистент в терминале
- **Терминал** — текстовый интерфейс командной строки (PowerShell на Windows, Terminal на macOS)
- **Провайдер/Прокси** — конечная точка сервиса: `https://litellm.geotech.user.events/v1`
- **Глобальный файл конфигурации** — `opencode.json` в директории `.config/opencode` домашнего каталога

## Установка

**macOS/Linux:**
```bash
curl -fsSL https://opencode.ai/install | bash
```
Закройте и снова откройте терминал.

**Windows:**
1. Установите Node.js LTS, если не установлен
2. Откройте PowerShell
3. Выполните: `npm install -g opencode-ai`
4. Закройте и снова откройте PowerShell

**Проверка:** `opencode --version`

## Настройка конфигурационного файла

**Расположение файла:**
- Windows: `C:\Users\<Имя_пользователя>\.config\opencode\opencode.json`
- macOS: `/Users/<Имя_пользователя>/.config/opencode/opencode.json`
- Linux: `/home/<Имя_пользователя>/.config/opencode/opencode.json`

**Создание папки:**
- Windows: `mkdir -Force $HOME\.config\opencode`
- macOS/Linux: `mkdir -p ~/.config/opencode`

Файл должен содержать строгий JSON (без комментариев и без лишних запятых) с настройками провайдера, списком моделей, моделями по умолчанию и настройками разрешений.

## Добавление API-ключа

1. Перейдите в папку проекта и запустите `opencode`
2. Введите команду `/connect`
3. Выберите «Other» из списка провайдеров
4. Введите ID провайдера: `litellm`
5. Вставьте личный API-ключ
6. Выйдите и перезапустите OpenCode

## Выбор модели

Используйте команду `/models` для переключения между доступными моделями.

## Проверка

Запустите OpenCode и отправьте простой запрос. При успешном ответе настройка завершена.

## Диагностика

Проверьте:
- Команда `opencode` работает
- Путь к файлу правильный
- JSON корректен
- ID провайдера согласован
- Ключ вставлен полностью
- `baseURL` содержит суффикс `/v1`
- ID модели точный
- Файл сохранён
- Интернет-соединение доступно

При сохраняющихся проблемах: alsu.yarulina@geotech.in

## Безопасность

> API-ключ действует на сотрудника, которому он был выдан. Не передавайте ключ и не публикуйте в чатах, документах, скриншотах. OpenCode хранит учётные данные в `~/.local/share/opencode/auth.json` — исключайте из коммитов в репозиторий.
