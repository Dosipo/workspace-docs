Приватный репозиторий видят только владелец репозитория и пользователи, которым выдан доступ.

## Что потребуется

- Аккаунт GitHub или GitLab для владельца репозитория
- Имя пользователя GitHub или email пользователей, которым нужен доступ

> **Предупреждение:** Не выдавайте доступ шире, чем нужно для работы.

## Как создать приватный репозиторий

1. Войдите в GitHub
2. В правом верхнем углу нажмите `+`
3. Выберите New repository
4. Введите название репозитория
5. Добавьте описание (опционально)
6. В разделе видимости выберите **Private**
7. Настройте дополнительные параметры (README, .gitignore, лицензия)
8. Нажмите Create repository

**Результат:** репозиторий с видимостью Private, невидимый пользователям без доступа.

## Как предоставить доступ (личный аккаунт GitHub)

1. Откройте репозиторий на GitHub
2. Перейдите в Settings
3. В левом меню выберите Collaborators
4. Нажмите Add people
5. Введите имя пользователя GitHub или email разработчика
6. Выберите найденного пользователя
7. Нажмите Add ... to repository

**Результат:** Разработчик получит приглашение; доступ начнёт работать после принятия.

## Какие права выбрать

| Право | Описание |
|-------|----------|
| **Write** | Достаточно для разработки (скачивание кода, создание веток, отправка изменений) |
| **Admin** | Только для управления настройками репозитория |
| **Read-only** | Недоступно в личном аккаунте — требуется организация |

## Что должен сделать разработчик

1. Открыть приглашение GitHub
2. Принять приглашение
3. Настроить SSH-ключ
4. Клонировать проект: `git clone git@github.com:ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ.git`
5. Перейти в папку: `cd название_проекта`
6. Проверить доступ: `git pull`

## Частые проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| Разработчик не видит репозиторий | Приглашение не принято | Принять приглашение на GitHub |
| Приглашение не пришло | Неверное имя пользователя/email | Проверить данные и отправить повторно |
| `git clone` запрашивает логин и пароль | Используется HTTPS вместо SSH | Скопировать SSH-адрес |
| Permission denied (publickey) | SSH-ключ не настроен | Настроить SSH-ключ и добавить в GitHub |
| Нельзя выбрать read-only доступ | Репозиторий в личном аккаунте | Перенести в организацию |
