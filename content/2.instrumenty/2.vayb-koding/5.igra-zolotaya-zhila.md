Вы соберёте игру, ставя ИИ задачи обычным языком и проверяя результат. Знать язык программирования не нужно. Что такое вайб-кодинг — на странице [Что такое вайб-кодинг](/instrumenty/vayb-koding/chto-takoe).

Размытая просьба «сделай игру» даёт непредсказуемый результат. Короткий план и маленькие шаги с проверкой дают рабочую программу даже на простой и быстрой модели.

## Что будем делать

Браузерная игра «Золотая жила»: бур копает шахту вниз, собирает руду, продаёт её на поверхности и покупает улучшения. Игра получится в одном файле `index.html`, без библиотек и установки. Открывается двойным кликом в браузере.

## Какой инструмент нужен

Пример показан на VS Code + Claude Code. Те же шаги работают в любом ИИ-помощнике для кода (Cursor, Windsurf, Copilot, Cline), который читает и редактирует файлы в папке проекта.

## Модели для фаз

| Фаза | Тип модели | Пример |
|------|-----------|--------|
| Фаза 0 (архитектура) | Сильная модель (effort medium) | terra |
| Фазы 1–6 (код) | Простая и быстрая (effort low) | luna (openai/gpt-5.6-luna) |

Сильная модель один раз продумывает план. Простая модель пишет код короткими правками по этому плану — так быстрее и дешевле. Если простая модель не справилась за 2 попытки, отправьте тот же промпт сильной модели.

## Подготовка

1. Создайте пустую папку, например `gold_miner`
2. Откройте её в VS Code: меню File → Open Folder
3. Откройте Claude Code (или другой ИИ-помощник) в этой папке

После каждой удачной фазы копируйте `index.html` в отдельную папку, например `backup/phase1a/`. Если следующая фаза что-то сломает, можно вернуть рабочую версию.

## Как работать с промптами

Игра собирается за 8 фаз. Для каждой фазы:

1. **Откройте новый чат.** В Claude Code — команда `/clear`. Новый чат нужен на каждую фазу, чтобы модель не путалась в прошлых разговорах.
2. **Выберите модель** для фазы (команда `/model` в Claude Code).
3. **Скопируйте промпт целиком** и отправьте.
4. **Дождитесь ответа** «Готово: …». Если инструмент спрашивает разрешение на изменение файла, разрешите.
5. **Проверьте результат:** откройте `index.html` двойным кликом или обновите страницу (F5).
6. **Сохраните копию** `index.html`, если фаза прошла успешно.

## Техники промптинга

| Техника | Зачем | Где |
|---------|-------|-----|
| Роль и контекст | Модель понимает, кто она и для чего план | Фаза 0 |
| Теги `<task>`, `<rules>`, `<acceptance>` | Задача, ограничения и критерий готовности не смешиваются | Все промпты |
| Общий контракт в файле (ARCHITECTURE.md) | Каждая фаза опирается на один и тот же план | Фазы 1–6 |
| Лимит объёма («не больше 80 строк») | Модель не добавляет лишнего | Все промпты |
| Точечные правки вместо переписывания файла | Не ломается то, что уже работает | Фазы 1b–6 |
| Новый чат на каждую фазу | Модель не путается в старом контексте | Все фазы |

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|-----------|
| Ошибка в консоли браузера (F12 → Console) | В том же чате: «Исправь эту ошибку точечной правкой, больше ничего не меняй: <текст ошибки>» |
| Модель переписывает файл целиком | Добавьте первой строкой промпта: «ВАЖНО: только точечные правки» |
| Сломалось то, что раньше работало | Верните `index.html` из сохранённой копии и повторите промпт в новом чате |
| Простая модель не справилась за 2 попытки | Отправьте тот же промпт сильной модели |
| Ответ генерируется больше 3 минут | Остановите генерацию (кнопка или Esc), верните `index.html` из копии и повторите промпт |
| Игра не реагирует на клавиши | Кликните мышкой по игре. Если не помогло: «храни клавиши по event.code, а не event.key» |

## Результат и что дальше

Готовая игра — один файл `index.html` без зависимостей; его можно отправить коллеге, он откроется в любом браузере.

Для доработки (новый тип руды, враги, таблица рекордов) используйте тот же шаблон: новый чат, «Следуй ARCHITECTURE.md», задача в `<task>`, те же `<rules>` и лимит строк.

Подробнее о написании промптов — в разделе [Как написать промпт](/praktiki/napisat-prompt).
