Вайб-кодинг — это работа с ИИ, при которой вы описываете задачу обычным языком, а ИИ сам пишет код, создаёт файлы и запускает команды.

ИИ работает как цифровой помощник — не просто даёт ответы в чате, а выполняет задачи и показывает результаты.

## Для не-программистов

Знание программирования не требуется. Типичные применения:
- Объединение Excel-файлов в сводные отчёты
- Сравнение версий документов для поиска различий
- Организация файлов: переименование, сортировка, дедупликация
- Создание простых веб-страниц или калькуляторов
- Генерация презентаций и учебных материалов
- Автоматизация еженедельных повторяющихся операций

## Возможности и гибкость

- **Выбор среды:** выбирайте удобные инструменты, не теряя работу
- **Гибкость моделей:** назначайте простые задачи быстрым моделям, сложные — мощным
- **Правила:** задавайте рабочие предпочтения для постоянного применения
- **Интеграции:** подключайтесь через MCP к GitHub, Jira, Confluence, базам данных и файловым хранилищам

## Доступные среды разработки

| Среда | Описание | Настройка |
|-------|----------|-----------|
| Visual Studio Code | Редактор кода с панелью проектов и встроенным ИИ-ассистентом | Установка, затем Claude Code или Kilo Code |
| OpenCode | Опенсорс-терминальный ИИ-ассистент | Установка с подключением API-ключа |

## Начало работы

1. Выберите и настройте среду разработки
2. Создайте отдельную рабочую папку
3. Опишите задачу ИИ
4. Проверьте результаты и запросите исправления

Практический пример — [делаем игру «Золотая жила»](/instrumenty/vayb-koding/igra-zolotaya-zhila).

## Безопасность

> Не передавайте ИИ конфиденциальные и персональные данные, пароли, токены и реальные клиентские базы.

Вы несёте ответственность за проверку результатов — ИИ-системы могут допускать ошибки.
