Эта инструкция нужна для установки редактора кода Visual Studio Code. Он понадобится для написания кода с помощью ИИ через расширения Kilo Code и Claude Code.

> Важно: Нужно установить именно Visual Studio Code. У него синяя иконка. Не путайте с Visual Studio.

## Шаги

1. Откройте сайт Visual Studio Code: https://code.visualstudio.com/download
2. Нажмите кнопку загрузки для Windows
3. Скачайте установочный файл
4. Откройте скачанный файл
5. Пройдите установку, оставляя стандартные настройки
6. После установки откройте Visual Studio Code
