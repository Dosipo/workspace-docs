Канал — это общее пространство, где несколько пользователей и несколько ИИ-моделей могут общаться одновременно.

## Создание канала

1. В левой панели найдите раздел **Каналы**
2. Нажмите **Создать канал** или кнопку нового канала
3. Укажите название канала, например: `research`, `fhir`, `ontology`, `project-team`
4. Добавьте участников по фамилии через поиск
5. При необходимости настройте права доступа (Публичный — доступен всем сотрудникам)
6. Откройте созданный канал

## Вызов модели в канале

**Модели в канале не отвечают автоматически.** Чтобы обратиться к модели, используйте символ `@`.

Примеры:
```
@gpt-4o Составь краткое резюме обсуждения
@claude Проанализируй аргументы выше и найди слабые места
@gti/claude-sonnet-4-6 О чём этот документ?
```

После ввода `@` платформа показывает список доступных пользователей и моделей. Выберите нужную модель из выпадающего списка.

## Общение нескольких пользователей с моделью

**Иван:**
```
@gpt-4o Подготовь план проекта.
```

**GPT-4o:**
```
Предлагаю следующий план...
```

**Мария:**
```
@claude Проверь этот план и предложи улучшения.
```

**Claude:**
```
План хороший, однако рекомендую...
```

Все ответы сохраняются в общей истории канала и доступны всем участникам.

## Треды

Для отдельных обсуждений используйте треды:

1. Откройте сообщение
2. Нажмите «Ответить в треде»
3. Продолжайте обсуждение внутри треда

Модели можно вызывать через `@` как в основном канале, так и внутри треда.

## Ограничения при работе с документами

В некоторых версиях Open WebUI есть известная проблема:
- Документ (PDF, DOCX и т.д.) отображается в канале
- Пользователь видит прикреплённый файл
- Модель, вызванная через `@model`, может не получить документ в контексте и ответить, что файл отсутствует

Известные баги:
- GitHub Issue #24896
- GitHub Issue #23686
