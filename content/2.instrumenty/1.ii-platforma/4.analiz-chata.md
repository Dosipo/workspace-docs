Иногда нужно получить ответ от одной модели, а затем проверить его другой. Этот подход помогает:

- Находить фактические ошибки
- Проверять логику рассуждений
- Выявлять упущенные риски
- Получать альтернативные точки зрения на задачу
- Улучшать качество ответа

## Метод 1: Анализ текста чата

Самый простой подход — передать содержание диалога другой модели.

**Шаги:**
1. Откройте чат с исходным ответом
2. Скопируйте вопрос пользователя и ответ модели
3. Создайте новый чат
4. Выберите другую модель
5. Передайте ей содержание диалога и сформулируйте задачу

**Рекомендуемый промпт:**
```
Проанализируй следующий диалог. Проверь на фактические ошибки, логические противоречия,
упущенные риски и слабые места в ответе.
```
Затем вставьте текст диалога.

## Метод 2: Использование экспорта чата

1. Экспортируйте чат
2. Создайте новый чат с другой моделью
3. Предоставьте экспортированный диалог как файл для анализа

## Два типа анализа

### А. Анализ текста чата

Вторая модель получает только:
- Вопрос пользователя
- Ответ первой модели
- Историю разговора
- ID использованных инструментов

### Б. Анализ процесса получения ответа

В некоторых сценариях модели используют дополнительные возможности платформы:
- Поиск по файлам
- Работа в Open Terminal
- Базы знаний
- Специализированные инструменты

Для полного аудита нужно знать:
- Какие файлы использовались
- К каким источникам данных был доступ
- Какие инструменты вызывались
- Какие промежуточные результаты получены

Если эта информация недоступна, вторая модель может проанализировать только текст ответа, но не весь процесс.
