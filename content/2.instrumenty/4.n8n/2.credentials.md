## Что такое credentials?

Credentials — сохранённый в n8n доступ к внешнему сервису: API-ключ, логин/пароль или токен. Ключ вводят один раз, дают ему имя (например, «OpenAi account 2») и выбирают по имени в нодах workflow, не раскрывая сам ключ.

## Общие credentials в корпоративном n8n

Корпоративные credentials общие для сотрудников и создаются администраторами. Поэтому:

- личные ключи для моделей, Nextcloud и баз данных создавать, хранить и передавать не нужно;
- когда администраторы обновляют общие credentials, изменения применяются ко всем пользователям.

Credentials доступны в двух вкладках: «Shared with you» (доступные credentials) и «Personal» (созданные пользователем).

## Список доступных credentials

| Credential | Назначение |
|-----------|-----------|
| **OpenAi account 2** | Для OpenAI-моделей (генерация текста и изображений) |
| **BaseGeotechModelCreds** | Для моделей эмбеддингов (перевод текста в векторы для семантического поиска) |
| **n8n LLM api key** | Доступ к языковым моделям через HTTP Request ноды (тип Header Auth) |
| **transcribe api key** | Транскрипция аудио в текст через HTTP Request (тип Header Auth) |
| **LiteLLM OCR New** | Распознавание текста в изображениях и PDF через ноду LiteLLM OCR |
| **NextCloud account** | Чтение и запись файлов в Nextcloud |
| **Postgres n8n** | Подключение к базе данных PostgreSQL |

## Если credentials не загружаются

После импорта workflows — проверьте ноды, обращающиеся к внешним сервисам, и вручную выберите правильный credential. Если нужный credential недоступен, проверьте вкладку «Shared with you» — если его нет, доступ не предоставлен.
