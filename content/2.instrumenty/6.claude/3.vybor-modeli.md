Эта страница помогает выбрать модель Claude под задачу. Это оценка по [бенчмаркам](/instrumenty/claude/benchmarki) и цене, а не гарантия: проверьте выбор на своих данных. Рекомендации на 05.11.2026.

::tip
Начните с Sonnet 5.5. Если качества не хватает, сначала повысьте effort, потом переходите на Opus 5.5. Anthropic советует: подстройка effort часто эффективнее смены модели.
::

## Задача → модель

| Задача | Модель | Почему |
|---|---|---|
| Кодинг и агенты | Sonnet 5.5 | Лидирует в Terminal-Bench 4.0 (70,6 против 66,4 у Opus 5.5), близок к Opus 5.5 по CursorBench (55,5 и 57,8), цена вдвое ниже |
| Многочасовые автономные сессии, рефакторинг | Opus 5.5 | Выше по FrontierCode (54,4 при max) и Humanity's Last Exam; Anthropic рекомендует его для долгих автономных агентов |
| Самые сложные рассуждения, глубокое исследование | Fable 5.1 | Anthropic называет её самой способной, но по тестам анонса она часто ниже Opus 5.5 при цене в 2,5 раза выше. Берите, только если Opus 5.5 на xhigh или max не хватило |
| Быстрые массовые задачи: классификация, извлечение, маршрутизация | Haiku 5.5 | Самая низкая цена и задержка; Anthropic рекомендует её для таких задач. Для сложного кодинга слаба (Terminal-Bench 39,2) |
| Длинные документы | Sonnet 5.5; Haiku 5.5 для простых случаев | Контекст 1M у всех четырёх, выбор идёт по цене и качеству. Независимых тестов длинного контекста нет |
| Анализ данных | Sonnet 5.5 | Входит в сценарии Sonnet по версии Anthropic. Прямого бенчмарка по анализу данных нет |
| Тексты и переводы | Sonnet 5.5; Haiku 5.5 для массовых | Профильных бенчмарков нет, уверенность низкая. Русское слово — около 2–2,5 токена |
| Excel и n8n | Sonnet 5.5; Opus 5.5 для тяжёлых цепочек; Haiku 5.5 для массовой обработки строк | В AutomationBench (Zapier) Opus 5.5 — 40,0, Fable 5.1 — 31,4; Sonnet и Haiku не замерены |

::caution
Haiku 5.5 дорожает в 5 раз при промпте длиннее 100K токенов: $0,50 / $2,50 вместо $0,10 / $0,50 за 1M. Для длинных документов считайте стоимость заранее.
::

## Что доступно у нас

В таблице выше речь о моделях Anthropic. В нашей платформе имена другие (`geotech/anthropic/…`, `gti/…`), а моделей поколения 5.5 в статьях нет. Соответствие имён и статусов — в [Модели Claude](/instrumenty/claude/modeli#соответствие-нашим-именам). Если 5.5 у вас недоступна, ближайшие замены:

- вместо Sonnet 5.5 — `gti/claude-sonnet-4-6` или `geotech/anthropic/claude-sonnet-5`;
- вместо Opus 5.5 — `geotech/anthropic/claude-opus-5` (справочник рекомендует его для сложного анализа).

Это предположение по ценам и поколениям: прямых замеров этих замен на наших задачах нет.
