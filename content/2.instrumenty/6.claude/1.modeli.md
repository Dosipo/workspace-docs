Справочник по ID, ценам и статусам моделей Claude на 11.11.2026. Это источник истины по ценам и ID Claude; список моделей, которые реально подключены у нас, ведёт [справочник моделей](/spravochnik/modeli).

Источники цифр — официальные страницы Anthropic (сверены 11.11.2026, при расхождении с другими страницами базы приоритет у них): [обзор моделей](https://platform.claude.com/docs/en/models/overview), [цены](https://platform.claude.com/docs/en/about-claude/pricing), [вывод из эксплуатации](https://platform.claude.com/docs/en/about-claude/model-deprecations).

## Актуальные модели

У всех четырёх: контекст 1M токенов, вывод до 128K (в Batch API до 300K с бета-заголовком), вход — текст и изображения, выход — текст, режим рассуждения adaptive thinking.

| Модель | ID в API | Вход / выход, $ за 1M | Скорость | Вывод не ранее |
|---|---|---|---|---|
| Fable 5.2 | `claude-fable-5-2` | 8 / 40 | Moderate | 09.11.2027 |
| Opus 5.5 | `claude-opus-5-5` | 4 / 20 | Moderate | 22.09.2027 |
| Sonnet 5.5 | `claude-sonnet-5-5` | 2 / 10 | Fast | 28.09.2027 |
| Haiku 5.5 | `claude-haiku-5-5` | 0,10 / 0,50 до 100K токенов; 0,50 / 2,50 свыше | Fastest | 07.10.2027 |

::warning
У Haiku 5.5 цена вырастает в 5 раз, если промпт длиннее 100K токенов.
::

Batch API даёт −50%. Чтение из кэша стоит $0,20 (Fable 5.2), $0,20 (Opus 5.5), $0,10 (Sonnet 5.5) и $0,01 / $0,05 (Haiku 5.5, до / свыше 100K) за 1M токенов. Fast mode стоит отдельно: $16 / $80 у Fable 5.2 и $8 / $40 у Opus 5.5; с Batch API он не работает.

Mythos 5.2 стоит как Fable 5.2 ($8 / $40), Mythos 5.1 и 5 — как Fable 5.1 и 5 ($10 / $50). Они доступны только организациям, прошедшим верификацию Anthropic, и для нас недоступны.

## Предыдущие модели

В обзоре моделей Anthropic все они в разделе Legacy («ещё доступны»), кроме Sonnet 4.5. В таблице статусов вывода у них состояние Active с датой «не ранее».

| Модель | ID | Вход / выход, $ | Статус | Вывод не ранее |
|---|---|---|---|---|
| Fable 5.1 | `claude-fable-5-1` | 10 / 50 | Legacy | 01.09.2027 |
| Fable 5 | `claude-fable-5` | 10 / 50 | Legacy | 09.06.2027 |
| Opus 5 | `claude-opus-5` | 5 / 25 | Legacy | 24.07.2027 |
| Opus 4.8 | `claude-opus-4-8` | 5 / 25 | Legacy | 28.05.2027 |
| Opus 4.7 | `claude-opus-4-7` | 5 / 25 | Legacy | 16.04.2027 |
| Opus 4.6 | `claude-opus-4-6` | 5 / 25 | Legacy | 05.02.2027 |

| Sonnet 5 | `claude-sonnet-5` | 2 / 10 | Legacy | 30.06.2027 |
| Sonnet 4.6 | `claude-sonnet-4-6` | 3 / 15 | Legacy | 17.02.2027 |

::caution
Sonnet 4.5 объявлен устаревшим с 30.09.2026 и снимается 30.11.2026. Замена по рекомендации Anthropic — `claude-sonnet-5-5`. Переведите на неё всё, что использует `geotech/anthropic/claude-sonnet-4-5`.
::

Для Haiku 4.5 дата «не ранее» 15.10.2026 прошла, но на 11.11.2026 Anthropic вывод не объявила. Opus 4 и 4.1, Sonnet 4 и 3.7, Haiku 3 и 3.5 уже выведены из эксплуатации.

## Соответствие нашим именам

Имена у нас — это названия моделей на ИИ-платформе, в n8n и в вайб-кодинге. Цены в [справочнике](/spravochnik/modeli) и [«Какую выбрать модель»](/instrumenty/ii-platforma/vybor-modeli) для Sonnet 5, Sonnet 4.6 и Opus 4.6 совпадают с официальными.

| Имя у нас | Модель Anthropic | Статус |
|---|---|---|
| `geotech/anthropic/claude-opus-5` | Opus 5 | Legacy, есть Opus 5.5 дешевле ($4 / $20 против $5 / $25) |
| `geotech/anthropic/claude-sonnet-5` | Sonnet 5 | Legacy, есть Sonnet 5.5 |
| `geotech/anthropic/claude-opus-4-5` | Opus 4.5 | Legacy, вывод не ранее 24.11.2026 |
| `geotech/anthropic/claude-sonnet-4-5` | Sonnet 4.5 | **Deprecated, вывод 30.11.2026** |
| `geotech/anthropic/claude-sonnet-4-6` | Sonnet 4.6 | Legacy |
| `geotech/anthropic/claude-haiku-4-5` | Haiku 4.5 | Legacy |
| `gti/claude-sonnet-4-6` | Sonnet 4.6 | Legacy |
| `gti/claude-opus-4-6` | Opus 4.6 | Legacy |

::note
Среди имён у нас нет моделей поколения 5.5 и Fable 5.2. Подключены ли они к платформе, не проверено: уточните у администраторов платформы.
::
