Здесь собраны ID, цены и статусы моделей Claude на 05.11.2026. Это главная страница по ценам и ID Claude; список моделей, которые реально подключены у нас, ведёт [справочник моделей](/spravochnik/modeli).

## Актуальные модели

У всех четырёх: контекст 1M токенов, максимальный вывод 128K (в Batch API до 300K с бета-заголовком), вход — текст и изображения, выход — текст, режим рассуждения adaptive thinking.

| Модель | ID в API | Вход / выход, $ за 1M | Скорость | Выход |
|---|---|---|---|---|
| Fable 5.1 | `claude-fable-5-1` | 10 / 50 | Slower | 01.09.2026 |
| Opus 5.5 | `claude-opus-5-5` | 4 / 20 | Moderate | 22.09.2026 |
| Sonnet 5.5 | `claude-sonnet-5-5` | 2 / 10 | Fast | 28.09.2026 |
| Haiku 5.5 | `claude-haiku-5-5` | 0,10 / 0,50 до 100K токенов; 0,50 / 2,50 свыше | Fastest | 07.10.2026 |

::warning
У Haiku 5.5 цена вырастает в 5 раз, если промпт длиннее 100K токенов.
::

Прочее по ценам: Batch API даёт −50%. Чтение из кэша стоит $0,25 (Fable 5.1), $0,20 (Opus 5.5), $0,10 (Sonnet 5.5) и $0,01 / $0,05 (Haiku 5.5, до / свыше 100K) за 1M токенов. Fast mode стоит отдельно: $8 / $40 у Opus 5.5.

Модели Mythos 5.1 и 5 имеют те же цены, но доступны только организациям, прошедшим верификацию Anthropic. Для нас они недоступны.

## Соответствие нашим именам

Имена у нас — это названия моделей на ИИ-платформе, в n8n и в вайб-кодинге. Цены в [справочнике](/spravochnik/modeli) и [«Какую выбрать модель»](/instrumenty/ii-platforma/vybor-modeli) для Sonnet 5, Sonnet 4.6 и Opus 4.6 совпадают с официальными.

| Имя у нас | Модель Anthropic | Статус |
|---|---|---|
| `geotech/anthropic/claude-opus-5` | Opus 5 | Legacy, есть Opus 5.5 дешевле и сильнее |
| `geotech/anthropic/claude-sonnet-5` | Sonnet 5 | Legacy, есть Sonnet 5.5 |
| `geotech/anthropic/claude-opus-4-5` | Opus 4.5 | Active, вывод не ранее 24.11.2026 |
| `geotech/anthropic/claude-sonnet-4-5` | Sonnet 4.5 | **Deprecated, вывод 30.11.2026** |
| `geotech/anthropic/claude-sonnet-4-6` | Sonnet 4.6 | Active |
| `geotech/anthropic/claude-haiku-4-5` | Haiku 4.5 | Active |
| `gti/claude-sonnet-4-6` | Sonnet 4.6 | Active |
| `gti/claude-opus-4-6` | Opus 4.6 | Active |

::note
Моделей поколения 5.5 в наших статьях нет. Подключены ли они к платформе, не проверено: уточните у администраторов платформы.
::
