MCP Market (mcpmarket.com) — публичный каталог MCP-серверов, MCP-клиентов и навыков агентов (Agent Skills). На сайте он описан как справочник серверов и клиентов, которые подключают ИИ-агентов к внешним инструментам.

## Что в каталоге

На 12.11.2026 в каталоге 53 814 серверов; счётчик на сайте меняется. Основные разделы навигации — MCP Servers, Agent Skills, Sell Skills и Hub (Connect). Полный перечень разделов, блоков главной страницы и категорий — в справочнике [Категории и разделы MCP Market](/instrumenty/mcp-market/categories).

## Как найти сервер

Сервер ищут тремя способами:

- через поиск;
- по категориям (всего 24);
- по рейтингам: Top 100 MCP Servers, Top 100 Agent Skills и дневные рейтинги.

## Реклама и добавление материалов

На сайте есть спонсорские размещения: в блоке Official MCP Servers есть спонсорский слот. Реклама оформляется через страницу Advertise.

Свой сервер добавляют через страницу Submit, навыки продают через страницу Sell. По вопросам сайта пишите на support@mcpmarket.com.
