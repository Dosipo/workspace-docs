MCP Market — публичный каталог, где собраны MCP-серверы, MCP-клиенты и навыки агентов (Agent Skills). На сайте он описан как справочник серверов и клиентов, которые подключают ИИ-агентов к внешним инструментам.

## Что даёт сайт

Каталог помогает найти готовый MCP-сервер под нужный внешний сервис, не собирая его самостоятельно. На 12.11.2026 в нём 53 814 серверов, счётчик на сайте меняется.

Основные разделы навигации: MCP Servers, Agent Skills, Sell Skills и Hub (Connect). Отдельно показаны блоки Official MCP Servers, Featured MCP Servers, Top MCP Servers, Latest MCP Servers, MCP Clients и Top Agent Skills.

## Как искать

Сервер ищут тремя способами: через поиск, по категориям или по рейтингам Top 100 MCP Servers и Top 100 Agent Skills. Есть и дневные рейтинги. Полный перечень категорий — на странице [Категории и разделы MCP Market](/instrumenty/mcp-market/categories).

## Что учитывать

На сайте есть спонсорские размещения: в блоке Official MCP Servers есть спонсорский слот. Реклама оформляется через страницу Advertise.

Свой сервер можно добавить через страницу Submit, навыки — продавать через страницу Sell. По вопросам сайта пишите на support@mcpmarket.com.
